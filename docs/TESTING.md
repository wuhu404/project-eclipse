## 重要前提（请勿高估以上结果）

- **通关是由脚本机器人完成的，不是人类玩家。** 机器人通过测试钩子注入按键、直接设定瞄准方向（相当于完美瞄准），
  并用导航网格寻路。它验证的是「逻辑链路可以走通」，不是「手感好不好」。
- **机库首战之后机器人开启了无敌。** 机器人不会躲避攻击、也不会去捡血包。关闭无敌（`GOD=0`）时，
  它能打过机库、门禁卡伏击和实验室，但会在工业大厅被重装机器人的迫击炮/砸地击杀。
  因此「不开无敌从头打到通关」**没有被验证**，难度平衡未经人类试玩调校。
- 部分检查用测试钩子传送玩家以缩短流程（如回到靶场、进入机库观察 AI）。

## 未测试 / 无法在本环境验证

- **真人试玩**：射击手感、后坐力、移动手感、关卡节奏、实际通关时长（10–15 分钟是设计目标，未实测）。
- **音频**：测试以静音运行。音频代码执行无报错，但枪声、脚步、音乐的实际听感没有人听过。
- **性能**：本 VM 只有软件渲染，1280×720 下帧时间约 80–90 ms（约 11–12 FPS），不代表真实硬件。
  **没有在任何带 GPU 的机器上测过帧率**，60 FPS 目标未验证。
- **浏览器兼容性**：仅在 Chrome 156 运行过；Firefox / Safari / Edge 未测。
- 困难难度、长时间游玩的内存表现、非 16:9 的超宽屏/小窗口下 HUD 排版。

## 已知限制

- 只有一个关卡；没有手柄和触屏支持，没有按键重绑定。
- 生产构建是单个约 5 MB 的 JS 包（未做代码分割）。
- 敌人与武器模型由基础几何体组合而成，没有骨骼动画；动作为程序化的摆动/后坐/倾斜。
- 敌人寻路基于 0.5 m 的平面导航网格：敌人不会上高架走道，飞行单位不寻路。
- 可爆油桶会被敌人流弹引爆，站在油桶旁边交火有风险。
- `window.__ECLIPSE__` 调试钩子（含无敌、传送）在生产构建中仍然存在。
